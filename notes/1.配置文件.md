## tsconfig.json 配置文件

### baseUrl 和 paths
- 情景
~~~ts
import { isObject } from "../../shared";
// 这种相对路径导入方式在项目中可能会变得冗长和难以维护，特别是当文件层级较深时。
~~~
- 如果你想在项目中使用路径别名来简化模块导入，可以在 tsconfig.json 文件中添加以下配置：
~~~json
    "baseUrl": ".",// 以项目根目录为基础路径
    "paths": { // 配置路径别名,方便导入模块
      "@vue/*": ["packages/*/src"] // 将 @ 映射到 packages 目录
    }
~~~

- 这样，你就可以使用路径别名来导入模块了：
~~~ts
import { isObject } from "@vue/shared";
~~~
