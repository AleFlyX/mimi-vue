## Effect
Effect 是一个函数，接收一个函数作为参数，并在组件渲染后执行该函数。它可以用来处理副作用，例如数据获取、订阅、手动修改 DOM 等。

```js

export let activeEffect=null;
class ReactiveEffect{
    active=true;// 这个effect是否激活，默认为true
    // fn是用户传入的函数，
    // scheduler是fn中依赖的数据发生变化时，用户自定义的调度函数
    constructor(public fn,public scheduler?){
    
    }

    run(){
        if(!this.active){
            return this.fn();// 如果这个effect不激活了，就直接执行fn，不收集依赖
        }
        let lastEffect=activeEffect; // 用于记录嵌套effect，
        try{
     
            activeEffect=this;
            // console.log("activeEffect:",activeEffect)
            // 这里的this指向ReactiveEffect实例，调用run方法时会执行fn函数，
            // fn函数中会读取响应式对象中的数据，这样就会触发get方法，在get方法中会收集依赖    
            return this.fn();// 执行传入的函数以触发依赖收集
        }finally{
            activeEffect=lastEffect;
        }
        //让fn执行，fn中会读取响应式对象中的数据，这样就会触发get方法，在get方法中会收集依赖
        
    }
}

export function effect(fn,options={}) {
    // 创建一个响应式effect实例，fn是用户传入的回调函数，options中可能包含scheduler

    const _effect=new ReactiveEffect(fn,()=>{
        //scheduler是用户自定义的调度函数，当响应式对象中的数据发生变化时，会调用这个调度函数
        _effect.run();
    });
    _effect.run();
    console.log("_effect run ")
    return _effect;
}
```
### stage1: 依赖收集
在上面的代码中，我们定义了一个 `ReactiveEffect` 类，它有一个 `run` 方法来执行用户传入的函数，并在执行过程中收集依赖。`effect` 函数创建了一个 `ReactiveEffect` 实例，并立即调用它的 `run` 方法来执行用户的函数。当用户的函数中访问响应式数据时，`get` 方法会被触发，从而收集依赖。
### stage2: 调度器
在 `ReactiveEffect` 类的构造函数中，我们接受了一个可选的 `scheduler` 参数。当响应式数据发生变化时，`scheduler` 函数会被调用，进而调用 `run` 方法重新执行用户的函数。
### stage3: 嵌套 effect
* 在 `run` 方法中，我们使用了一个 `lastEffect` 变量来记录当前正在执行的effect接收的`fn`函数，在执行最外层的effect过程中如果遇到了嵌套在此`fn`中的effect函数，就可以借助lastEffect记录当前正在执行的effect fn

* 然后进入嵌套的effect函数，正常执行，等嵌套的effect函数执行完毕后，通过进入`finally`块将activeEffect恢复为之前的值，这样就可以正确地处理嵌套effect的情况，确保每个effect都能正确地收集依赖并在数据变化时重新执行。

* 相关代码段
```js
run(){
    if(!this.active){
        return this.fn();// 如果这个effect不激活了，就直接执行fn，不收集依赖
    }
    let lastEffect=activeEffect; // 用于记录嵌套effect，
    try{
        activeEffect=this;
        return this.fn();// 执行传入的函数以触发依赖收集
    }finally{
        activeEffect=lastEffect;
    }
}
``` 
* 调用
```js
const state=reactive({name:'zhangsan',age:20})
effect(()=>{ 
    console.log('1',state.name) //外层effect 1
    effect(()=>{
        console.log('2',state.age) // 内层effect
    })
    console.log('3',state.name) //外层effect 2
        
})
// 输出结果： 
// 1 zhangsan
// 2 20   
// 3 zhangsan
```
