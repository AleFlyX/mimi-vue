## 安装本地写好的依赖
- 如果我想在reactivity中使用shared中的函数，首先需要安装shared包的依赖，在根目录下执行以下命令：
```bash 
pnpm install @vue/shared --filter @vue/reactivity
``` 
但是这样安装后，shared的包是优先从npm仓库中安装的，而不是本地的包
- 解决方法：在根目录下执行以下命令，安装本地的包：
```bash
pnpm install @vue/shared --filter @vue/reactivity --prefer-local
# 或者
pnpm install @vue/shared --workspace --filter @vue/reactivity
```
- 这样就会优先安装本地的包了，安装完成后，在reactivity中就可以使用shared中的函数了。

- 此时的reactivity中的package.json文件中的依赖项如下：
```json
    "dependencies": {
        "@vue/shared": "workspace:*" // * 表示使用任意版本
    }
```
- 并且在reactivity文件夹中，会产生node_modules文件夹，并且在node_modules文件夹中会有一个@vue/shared的软链接，指向根目录下的packages/shared/src/index.ts文件，这样就可以在reactivity中使用shared中的函数了。
